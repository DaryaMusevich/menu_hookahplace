# HookahPlace — электронное меню

Готовый сайт меню для гостей: одна страница, открывается по QR, без приложений и сборки.
Эта папка — **корень репозитория**: загружайте её содержимое, а не саму папку.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | само меню (RU / EN) — сюда ведёт QR |
| `presentation.html` | презентация концепции (для команды, закрыта от индексации) |
| `menu-b.html`, `menu-c.html` | альтернативные варианты дизайна |
| `qr-print.html` | лист A4 с QR для столов — печать из браузера |
| `assets/` | стили, данные меню, шрифты, иллюстрации, QR |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Адрес меню: `/` · Английская версия: `/?lang=en` · Презентация: `/presentation.html`

## Загрузка на GitHub Pages — 6 шагов

Подробный разбор каждого шага, с частыми ошибками и вариантами через GitHub Desktop
или командную строку — в файле **GITHUB.md** в этой же папке.

1. **Создать репозиторий.** github.com → *New repository* → имя `hookahplace-menu` →
   **Public** → *Create repository*.
   (Pages бесплатен только для публичных репозиториев.)
2. **Загрузить файлы.** На странице репозитория → *uploading an existing file* →
   перетащите **всё содержимое** этой папки (файлы и папку `assets`) → *Commit changes*.
   Проще всего через GitHub Desktop или командную строку:
   ```bash
   cd site
   git init && git add . && git commit -m "Menu"
   git branch -M main
   git remote add origin git@github.com:USERNAME/hookahplace-menu.git
   git push -u origin main
   ```
3. **Включить Pages.** Settings → *Pages* → Source: **Deploy from a branch** →
   Branch: **main**, папка **/(root)** → *Save*.
4. **Подождать 1–2 минуты.** Адрес появится сверху:
   `https://USERNAME.github.io/hookahplace-menu/`
5. **Проверить на телефоне.** Открыть ссылку, переключить RU / EN, пролистать до подвала —
   QR там уже ведёт на этот адрес.
6. **Напечатать QR.** `qr-print.html` → Cmd/Ctrl+P → A4, масштаб **100%** →
   8 карточек для столов со сквозной нумерацией `?t=1…8`.

## Свой домен (необязательно)

1. Settings → Pages → *Custom domain* → `menu.hookahplace.ru` → *Save*.
2. У регистратора добавить запись: тип **CNAME**, имя `menu`,
   значение `USERNAME.github.io`.
3. Дождаться сертификата (5–30 минут), включить **Enforce HTTPS**.

После смены адреса QR нужно перевыпустить: откройте `qr-print.html` на новом домене —
код пересчитается автоматически, старые наклейки придётся заменить.

## Как обновлять меню

Цены, описания и составы — в `assets/js/data.js` (русский) и `assets/js/data-en.js`
(английский, та же структура). Меняете файл → *Commit* → сайт обновляется через минуту.

Часы, адрес и телефоны — в блоке `venue` тех же двух файлов.

## Что стоит знать

- Сайт статический: нет базы данных, корзины и оплаты. Гость видит меню, звонит или
  зовёт официанта.
- Шрифты и картинки лежат локально — внешних запросов нет.
- GitHub Pages не поддерживает серверную логику: если понадобятся стоп-листы из кассы,
  нужен другой хостинг или сервис меню.
